# Arab Form Zod (@tahdeth/arab-form-zod)

مكتبة عربية متقدمة وخفيفة الوزن مصممة خصيصاً لتسهيل عملية التحقق من النماذج (Form Validation) في تطبيقات React و TypeScript، مبنية فوق **Zod** و **React Hook Form** لتوفير أداء عالي ورسائل خطأ عربية واضحة وجاهزة.

---

## 🚀 المميزات الرئيسية

- **دعم كامل للغة العربية:** رسائل خطأ افتراضية دقيقة ومصاغة بعناية باللغة العربية.
- **التحقق المتقدم من الأرقام (`arabNumberSchema`):** دعم النطاق العددي (`min`/`max`) والتحقق من عدد الخانات وطول الرقم (`length`, `minLength`, `maxLength`).
- **دعم شامل لأرقام الهواتف (`arabPhoneSchema`):** تغطية كاملة لجميع الدول العربية وأبرز الدول الأجنبية مع إمكانية تحديد الدولة المستهدفة.
- **التحقق من البريد الإلكتروني (`arabEmailSchema`):** معالجة ذكية وتنظيف للمسافات الزائدة تلقائياً.
- **تكامل تام:** مصممة للعمل بسلاسة مع React Hook Form عبر مكونات مساعدة وعرض أخطاء أنيقة (`ArabFieldError`).

---
